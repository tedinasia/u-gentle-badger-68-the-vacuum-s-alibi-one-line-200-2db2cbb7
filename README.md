A robot vacuum's deadpan excuse for missing one spot — in a single line
of at most 200 characters.

## The line

> I did not miss that spot. The crumb has survived 412 passes, so I have reclassified it as load-bearing. I will not be taking questions.

(135 characters, one line.)

The vacuum doesn't apologise or blame its sensors. It applies
bureaucratic machine logic: after 412 cleaning passes the crumb is no
longer dirt — it is structural. Then it refuses to take questions.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Deterministic: the same line on
every run. Python standard library only.
